# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-11-22

### Added
- Complete site structure with all main pages
- Homepage with hero section, services overview, and testimonials
- Chi Siamo page with company history timeline
- Servizi page with all service categories
- Contatti page with contact form and company information
- 6 detailed service pages (Impianti Elettrici, Automazione, Quadri, Energie Rinnovabili, Revamping, Servizi Aggiuntivi)
- Modern UI with Framer Motion animations
- Responsive design for all screen sizes
- Contact form with Resend email integration
- SEO meta tags and Open Graph support
- Custom UI components (Timeline, InfiniteMovingCards, AnimatedNumber, BentoGrid)
- WebP optimized images
- Dark mode support (system preference)
- Smooth page transitions
- Footer with company information and navigation
- Sticky navigation with scroll effects

### Technical
- React 19 with Vite build system
- Tailwind CSS for styling
- React Router for navigation
- Framer Motion for animations
- Lucide React for icons
- @unhead/react for SEO management
- Vercel serverless functions for contact form
