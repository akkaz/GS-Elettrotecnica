# GS Elettrotecnica - Sito Web Aziendale

Sito web moderno per GS Elettrotecnica Automazioni Industriali Srl, azienda leader nell'impiantistica elettrica e automazione industriale in Valle Camonica.

## 🚀 Tecnologie

- **React 19** - Framework UI
- **Vite** - Build tool e dev server
- **Tailwind CSS** - Styling
- **Framer Motion** - Animazioni
- **Lucide React** - Icone

## 📦 Installazione

```bash
npm install
```

## 🛠️ Sviluppo

```bash
npm run dev
```

Il sito sarà disponibile su `http://localhost:5173`

## 🏗️ Build

```bash
npm run build
```

I file di produzione saranno generati nella cartella `dist/`

## 📋 Struttura Progetto

```
├── public/              # Asset statici (immagini, logo)
├── src/
│   ├── components/      # Componenti riutilizzabili
│   │   ├── ui/         # Componenti UI avanzati
│   │   ├── Navigation.jsx
│   │   └── Footer.jsx
│   ├── pages/          # Pagine dell'applicazione
│   │   ├── HomePage.jsx
│   │   ├── ChiSiamoPage.jsx
│   │   ├── ServiziPage.jsx
│   │   └── ContattiPage.jsx
│   ├── styles/         # Stili globali e variabili
│   ├── utils/          # Utility functions
│   └── App.jsx         # Componente principale
└── index.html          # Entry point HTML
```
